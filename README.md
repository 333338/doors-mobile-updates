# DOORS Android 更新中心

这里公开发布 Android 安装包和经过签名的版本信息。游戏源代码、本地账号、密码和开发者签名私钥不存放在此仓库。

- [查看最新版本与安装包](https://github.com/333338/doors-mobile-updates/releases/latest)
- [版本信息文件](https://github.com/333338/doors-mobile-updates/releases/latest/download/version.json)

请覆盖安装，保留手机中的本地账号、设置与异常日志。Android 安装过程仍需用户确认。

## 当前迁移状态

1.0.8 已接入此更新中心。1.0.7 及更早版本需要手动覆盖安装 1.0.8 一次；之后发布新版，已接入的客户端会在游戏菜单检查更新。当前版本不会提示更新到自身。

手机上的版本文件访问和 1.0.7 附件下载已由测试者确认；1.0.8 的手机安装和后续新版提示仍需实际使用验证。开发电脑已完成 1.0.8 的完整公开下载及文件哈希校验。

能打开 GitHub 首页不等于能下载发布附件；具体网络访问情况需要实测。仓库保持公开可用时，文件托管不依赖开发者电脑开机。
